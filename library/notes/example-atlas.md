# Example atlas: what the public trail actually supports

This is a discovery and reproducibility map, not a quality ranking. Social originals were login-gated during this pass; descriptions below come through the [source-linked index](https://github.com/athemeroy/awesome-opus-5-5-videos), supplemented where possible by inspectable repositories. No media was watched or listened to. The index's own sampled-frame observations remain the index author's observations.

For the **eight-hour UMAP story**, the recovered link is this [ByteWoops indexed story](https://www.bytewoops.com/en/stories/riley-goodside-claude-opus-5-5-writes-and-animates-a-5-minute-explanation-of-umap-fo). It failed to load during research and may have a truncated slug. The [X profile discovery lead](https://x.com/tonichen/all) is not the original status. Attribution to Riley Goodside versus `@tonichen` remains unresolved.

The useful reconstruction is a production chain: input sources and assets → narrative/design decisions → code/media generation → measured narration/timing → render/repair → final artifact review. The [published skills](prompt-and-skill-map.md) supply inspectable methods for that chain. None closes the missing provenance of a specific viral run by association.
