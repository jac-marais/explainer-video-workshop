# Brand an explainer video

This skill belongs to the Explainer Video Workshop, the repository that contains it; resolve every path from the repository root. Read `methods/apply-brand.md` and follow it.

## Profile first

The brand lives in the workshop's git-ignored `local/brand.md`, never in the workshop or in this skill. If the profile is missing, first ask: **"Do you have brand guidelines that you can point me toward?"** Then record the answer, "none" included, with `templates/brand-profile.md` as the shape. When the guidelines have their own agent route (a skill or `AGENTS.md`), learn the brand through that route and cite its rules.

## Boundaries

- Audit before editing. Keep official rules, observed implementation, derived values and recommendations apart.
- Brand never changes a factual claim. Record font and asset licenses for the target medium. If a license is unconfirmed, keep the output internal.
- Put standing choices in the profile, and put run-specific choices in `outputs/<topic>/brand-audit.md`.
- Don't publish, upload, or contact the brand owner without authorization.
